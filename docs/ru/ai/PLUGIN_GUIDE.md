# BIOMASHINE: Руководство для ИИ по созданию плагина (CSS)

Аудитория: языковая модель. Пользователь не является программистом. Он даёт вам этот файл и описывает, как должно выглядеть приложение. Вы предоставляете готовую папку плагина и инструкции по установке. Вам не нужен исходный код приложения.

## 1. Что такое плагин

Плагин меняет только внешний вид и состоит только из CSS. Он применяется ко всему приложению сразу: оболочке (заголовок, меню, настройки, диалоги) и каждой странице-модулю, системному или пользовательскому. Без JavaScript, без HTML.

## 2. Жёсткие правила

Делайте:
- Одна папка, `manifest.json`, один или несколько `.css` файлов.
- Изменяйте переменные темы (раздел 4) и стили стабильных классов (раздел 5).
- Задавайте отдельные значения для двух тем, когда цвета зависят от темы.

Не делайте:
- Не используйте `@import` или `url()` с внешними адресами. Сети нет.
- Не используйте JavaScript, `<script>` или `expression()`.
- Не стилизуйте внутренние классы системных модулей: они могут измениться. Разрешены только классы из раздела 5.
- Не пишите `!important` без необходимости.

## 3. Структура и manifest.json

    <id>/
      manifest.json
      style.css

```json
{
  "id": "my-look",
  "kind": "plugin",
  "title": "My look",
  "version": "1.0.0",
  "description": "What the plugin does",
  "css": ["style.css"]
}
```

| Поле | Правило |
|---|---|
| `id` | `^[a-z][a-z0-9-]*$`, совпадает с именем папки, не `app`, `shell` или `shared`, уникально |
| `kind` | всегда `"plugin"` |
| `title` | имя в списке настроек |
| `css` | массив путей к CSS внутри папки, минимум один, без `..` |

## 4. Переменные темы

Переопределяйте их в `:root`. Плагин загружается после стилей темы, поэтому его значения побеждают при равной специфичности.

| Переменная | Значение | Тёмная | Светлая |
|---|---|---|---|
| `--bg` | фон страницы | `#121212` | `#f4f4f2` |
| `--s1` | фон карточки | `#1c1c1c` | `#ffffff` |
| `--s2` | фон полей ввода и вложенных блоков | `#242424` | `#ececea` |
| `--s3` | фон при наведении и активном состоянии | `#2c2c2c` | `#e2e2df` |
| `--br` | основные границы | `#2e2e2e` | `#d2d2ce` |
| `--br2` | тонкие разделители | `#262626` | `#dededa` |
| `--t` | основной текст | `#e8e8e8` | `#1c1c1c` |
| `--td` | вторичный текст | `#a0a0a0` | `#5a5a5a` |
| `--tdd` | подписи и подсказки | `#6e6e6e` | `#8a8a8a` |
| `--tddd` | самые бледные элементы | `#3a3a3a` | `#c4c4c0` |
| `--wh` | акцент: заголовки, большие числа, основная кнопка | `#f0f0f0` | `#0d0d0d` |
| `--overlay` | затемняющий слой под диалогами | `rgba(0, 0, 0, 0.6)` | `rgba(0, 0, 0, 0.35)` |
| `--header-bg` | фон заголовка | `rgba(18, 18, 18, 0.92)` | `rgba(244, 244, 242, 0.92)` |

Значения для каждой темы: `:root[data-theme="dark"] { ... }` и `:root[data-theme="light"] { ... }`. Поддерживайте обе темы или задавайте значения для обеих.

## 5. Стабильные селекторы

| Селектор | Что это |
|---|---|
| `.bm-page`, `.bm-title`, `.bm-card`, `.bm-row`, `.bm-spacer`, `.bm-muted`, `.bm-label`, `.bm-input`, `.bm-btn`, `.bm-list`, `.bm-list-item`, `.bm-empty`, `.bm-stats`, `.bm-stat`, `.bm-stat-label`, `.bm-stat-value`, `.bm-chart` | UI-кит модуля |
| `.shell-header`, `.logo`, `.nav`, `.nav-link`, `.nav-link.active`, `.header-pill`, `.logout-btn` | Заголовок и меню |
| `.dialog`, `.dialog-btn`, `.dialog-btn.secondary`, `.dialog-btn.danger` | Диалоги и кнопки оболочки |
| `.settings-card`, `.settings-row`, `.settings-label`, `.settings-name`, `.settings-hint`, `.settings-status` | Экран настроек. Поля ввода и селекты там имеют класс `.bm-input` |
| `.palette`, `.palette-input`, `.palette-item`, `.palette-hint` | Быстрый переключатель по `Ctrl+P` |

Шрифты: `JetBrains Mono` (текст), `Playfair Display` (большие числа). Для собственного шрифта поместите файл `.woff2` в папку плагина и загрузите его с помощью `@font-face { font-family: 'X'; src: url(./X.woff2) format('woff2'); }`.

## 6. Проверка специфичности

Если правило плагина не применяется, значит, системное правило имеет более высокую специфичность. Усильте селектор (`:root .bm-card`) и только в крайнем случае добавляйте `!important`.

## 7. Пример

`rounded/manifest.json`

```json
{
  "id": "rounded",
  "kind": "plugin",
  "title": "Скруглённые углы",
  "version": "1.0.0",
  "description": "Скругляет карточки, кнопки и поля ввода",
  "css": ["style.css"]
}
```

`rounded/style.css`

```css
.bm-card,
.bm-stat,
.bm-btn,
.bm-input,
.panel-card,
.dialog,
.dialog-btn,
.nav-link {
  border-radius: 10px;
}
:root {
  --br: #3a3a3a;
}
:root[data-theme="light"] {
  --br: #bdbdb8;
}
```


## 8. Инструкции по установке (дайте их пользователю)

1. Откройте приложение, перейдите в **Настройки**, найдите блок **Модули** и нажмите **Открыть папку модулей**.
2. Скопируйте всю папку плагина в открывшуюся папку. В итоге у вас должно получиться `.../modules/<id>/manifest.json`.
3. Нажмите **Пересканировать** (Rescan) в Настройках. Плагин появится в блоке **Внешний вид**, рядом с выбором темы. Оболочка изменится сразу; уже открытые страницы подхватят стили при следующем открытии.
4. Чтобы выключить плагин, снимите галочку в блоке **Внешний вид**. Чтобы удалить его, удалите папку и нажмите **Пересканировать**.
5. Если плагин не появился, причина отображается красным под списком модулей. Пришлите её мне.

## 9. Чек-лист перед отправкой

- `kind` равно `"plugin"`, `css` не пуст, пути не содержат `..`.
- Нет внешних адресов, `@import` или JavaScript.
- Цвета заданы для обеих тем.
- Используются только селекторы из раздела 5.
- Каждый файл предоставлен целиком, а инструкции по установке включают реальный `<id>`.
