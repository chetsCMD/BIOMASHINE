# A Canvas of Ideas

# I. Базовые модули

## 1. Модуль Dashboard

Собирается из виджетов со всех страниц. Вид имеет аналогу canvas из Obsidian — то есть расставлять их можно в свободном порядке.

Пример данных на этой странице:

- Текущий вес
- Продолжительность сна за сегодня
- Калории за сегодня

## 2. Модуль Analytics — объединённая система визуализации данных

Пример данных на этой странице:

- Графики за произвольный период
- Сравнение периодов
- Средние, минимумы и максимумы
- Корреляции между показателями
- Изменения в процентах
- Поиск закономерностей

## 3. Модуль Journal — хронологическая история наблюдений

Примеры данных на этой странице:

- Записи за конкретные даты
- События
- Комментарии к измерениям
- Свободные заметки
- Возможность восстановить любой день

## 4. Функция «Конструктор — Modules»

Не все пользователи умеют программировать и/или не хотят отдавать задачу AI. Иногда легче за минуту собрать страницу под себя из заранее заготовленных блоков: блок для текстового поля, блок для ввода даты. То есть это буквально конструктор, как лего. Соответственно нужно будет добавить те самые заранее заготовленные блоки. Ну и, логично, придерживаясь философии программы, дать возможность создавать пользовательские блоки. При расстановке страница (модуль) имеет вид canvas из obsidian, после сохранения закрепляют своё место.

# III. Инструментальные модули

## 1. Correlations — корреляции

Сопоставление разных показателей.

Например:

- Сон и настроение.
- Калории и вес.
- Тренировки и силовые показатели.
- Расходы и доходы.

## 2. Events — события

Фиксация значимых изменений.

Например:

- Начал принимать препарат.
- Изменил рацион.
- Переехал.
- Начал тренироваться.
- Перестал употреблять кофеин.

## 3. Anomalies — аномалии

Поиск необычных изменений.

Например:

- Вес изменился сильнее обычного.
- Расходы резко выросли.
- Сон стал значительно короче.
- Пульс отклонился от привычного диапазона.

## 4. Custom Metrics — пользовательские показатели

Например, пользователь хочет учитывать количество часов, проведённых за чтением научной литературы. Создаёт показатель — и пользуется им.

Например:

- Название.
- Тип данных.
- Единица измерения.
- Допустимый диапазон.
- Частота измерения.
- Формула расчёта.

## 5. Reports — отчёты

Формирование сводок за выбранный период.

Например:

- Неделя.
- Месяц.
- Год.
- Произвольный диапазон.

# IV.

## 1. Timeline — временная шкала жизни

Общая временная шкала, на которую выводятся события из всех установленных модулей.

Например:

- 3 ноября — сон 6 часов.
- 3 ноября — тренировка 45 минут.
- 3 ноября — расходы 850 ₽.
- 3 ноября — настроение 7/10.
- 3 ноября — 2200 ккал.

## 2. Experiments — эксперименты

Пользователь может самостоятельно проводить эксперименты над своим образом жизни.

Например:

Эксперимент: отказ от кофеина.

- Дата начала.
- Дата окончания.
- Исследуемые показатели.
- Исходные значения.
- Результаты.
- Выводы.

Можно сопоставлять показатели до, во время и после эксперимента.

## 3. Goals — цели

Общая страница, сборник всех целей.

## 4. Data Quality — качество данных

Он показывает:

- Сколько измерений пропущено.
- Какие показатели давно не обновлялись.
- Есть ли противоречивые записи.
- Есть ли подозрительные значения.
- Насколько полны данные за выбранный период.
